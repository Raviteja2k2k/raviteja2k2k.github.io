# raviteja2k2k.github.io

Source of the personal site of **Dr. Ravi Teja Thiriveedhi**: dental surgeon with 20 years of clinical practice and hospital leadership, now building governed multi-agent AI for healthcare.

Live at <https://raviteja2k2k.github.io>.

## What is here

| Path | Page |
|---|---|
| `index.html` | Home: selected work, how I work, contact |
| `work/whatsapp-crm/` | Case study: a 15-agent WhatsApp and Telegram platform (client anonymised) |
| `clinical/` | Clinical record, 2006 to now |
| `404.html` | Not-found page |

Plain HTML and one stylesheet. No framework, no build step at serve time, no analytics, no cookies and no third-party requests, so the site moves to any static host unchanged.
